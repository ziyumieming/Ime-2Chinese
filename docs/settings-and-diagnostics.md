# 设置与最近诊断

P5 已加入基础设置和诊断窗口。双击普通 `main.ahk` 后，从托盘选择“设置”，或双击托盘图标打开设置。输入功能仍需重喂或全功能测试入口，窗口上方会说明当前已接入的功能；打开设置本身不会启用输入功能。

## 基础设置

设置是唯一修改偏好的入口；托盘只保留暂停、设置、诊断和退出。可修改重喂/取回开关、登录后自启、两项快捷键、逐字发送间隔、选区长度上限和复制等待上限。自动切换与规则配置已移除。

快捷键字段只读，点击旁边“录制”，直接按 `Alt+Z`、`Alt+Shift+Z`、`Ctrl+Alt+F8` 等组合键，全部松开后完成；Esc、取消、离开窗口或关闭窗口取消。录制期间业务快捷键停用，结束后恢复，保存后新键生效。要求修饰键和一个按键，两项快捷键不能相同。系统保留的快捷键可能无法录制或使用，可选择其他组合；已有 INI 写法仍兼容。

范围沿用配置校验：发送间隔 1–1000ms、长度上限 1–500、复制等待 50–5000ms。默认仍为 10ms、50 字符、300ms。重喂只控制当前中文输入法内部模式；原 `RefeedTarget` 保留以兼容旧文件，不提供会让人误以为会切换输入法的设置选项。

“保存并应用”会重新读取有效配置，将窗口里真正修改的字段合并进去，保留文件中其他字段。若同一字段在窗口打开后也被文件改成另一个值，保存会拒绝并保留草稿。关闭或按 Esc 隐藏窗口，不保存改动；重新打开读取最新配置并放弃旧草稿。已删除“读取当前配置”和托盘重载按钮，重新打开本身不应用外部文件，保存后才应用。

保存使用现有配置、规则、热键和计时器统一应用路径。输入操作进行中时暂不保存；保存/注册/计时器失败保留之前有效的运行配置。暂停中保存仍保持暂停；普通入口里勾选重喂功能同时更新运行中的快捷键。没有字段变化时会应用最新有效文件，不为此重写文件。保存规范化格式，原注释不保留。文件编辑与保存之间没有系统级独占锁，编辑同一文件时仍应避免同时点击保存。

“开机自动启动”默认关闭，勾选并保存后，在当前用户启动目录生成 `Ime-2Chinese.lnk`，登录该用户后以普通权限启动。源码使用当前 AHK 程序和带引号的工程路径，保持当前运行入口：在重喂测试版里开启自启，下次也启动重喂版；普通入口开启则自动启动当前手动功能，编译版快捷方式直接指向 EXE，无需 AHK。取消勾选并保存会移除本工具的快捷方式；保存失败回滚自启改动。同名非本程序快捷方式不覆盖。移动 EXE/工程或更换 AHK 后重新保存设置以更新路径；若 Windows 禁用了该启动项，需要在系统启动应用设置中重新启用。

## 已冻结的自动切换

窗口自动切换停止后续开发；配置文件/规则编辑入口、规则示例及自动切换设置项已移除。普通偏好通过 GUI 修改。已有配置中的规则及隐藏偏好保存时保持兼容，不删除用户文件；历史全功能入口的既有行为保留作回归。不会创建独立规则文件，详见 [Issue #4 决策](issue-4-decisions.md)。

## 最近诊断

托盘“最近诊断”显示当前状态、源码/AHK 版本、入口、偏好、快捷键及操作过程。可见时随日志回调自动更新，连续步骤用窗口消息合并刷新；隐藏后退订。点击“刷新”主动重读内存，点击“清空记录”只清历史，不改变配置、原文缓存或输入法。

结果及阶段以中文显示，同时保留内部编号。每次重喂/取回包含操作编号、阶段耗时、目标进程/完整标题/焦点、可编辑判断、IME open/conversion 读回与错误、已取得的选中文本、剪贴板归属/序列、删除尝试、完成的发送调用数和缓存可用状态。停止阶段是观察结果，不保证已确定根因或实际上屏成功。最多 30 组、每组 64 步，过长字段标记截断；完全相同的连续记录合并首末时间及次数。提示继续去重；窗口不增加刷新计时器。

点击“导出文件”保存当前内存快照为 UTF-8 文本。只有主动导出才写文件，程序不自动保存或上传。日志只使用操作已经取得的数据，不额外复制、不读整框或密码内容。文本和标题可能包含你选中的私人内容，导出后可先核对再分享。字段上限及验收见 [决策与验收](issue-4-decisions.md)。

## 验证范围

自动检查覆盖字段冲突、配置合并、保存/绑定/计时器/自启故障回退、暂停及互斥。自启测试使用项目私有目录中的实际 .lnk，不修改真实启动项；录制用真实 InputHook 加注入按键事件检查规范化、全部松开、Esc/失焦及绑定恢复。隐藏自有窗口验证控件、日志回调和导出读回。实际组合键、Windows 登录启动和浏览器/记事本交互仍需 UAT。

界面接口依据 [AHK Gui](https://github.com/AutoHotkey/AutoHotkeyDocs/blob/v2/docs/lib/Gui.htm) 和 [Gui 事件](https://github.com/AutoHotkey/AutoHotkeyDocs/blob/v2/docs/lib/GuiOnEvent.htm)。当前进度见 [ROADMAP](../ROADMAP.md)。
