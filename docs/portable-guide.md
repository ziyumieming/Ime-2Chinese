# Ime-2Chinese 便携测试版

适用于 Windows 64 位；无需安装 AutoHotkey。解压到准备长期保留的文件夹，双击 `Ime-2Chinese.exe`。不要同时运行旧 demo 或 MVP 脚本。

1. 在浏览器或记事本中启用搜狗拼音，选中误输的英文字母，按 **Alt+Z** 重喂；中文候选由你选择。
2. **Alt+Shift+Z** 将最近缓存的原文插入当前可编辑位置，可重复、跨窗口使用。应用撤销使用 **Ctrl+Z**。
3. 双击托盘头像打开设置，可录制快捷键、修改重喂参数、启用当前用户登录后自启。关闭设置不会保存草稿。
4. 托盘“最近诊断”显示操作过程，可导出 UTF-8 文件。“暂停”释放业务快捷键，“退出”结束程序。

程序不显示右下角通知气泡；操作成功、跳过及失败原因请在“最近诊断”查看。

默认输入长度上限 50 字符，去掉空白后逐字发送，间隔 10ms。重喂需可编辑选区；无选区、网页正文、只读、密码或不明目标静默跳过。取回需可编辑位置及原文缓存；终端当前不支持。已绑定快捷键在无效场景可能仍被吞掉。

配置保存在 `%AppData%\ImeAssist\settings.ini`，兼容以前脚本的设置。诊断包含选中文本和完整窗口标题，导出前可自行检查；程序不自动上传或持久化日志。缓存只保留在本次运行的内存里。

启用登录自启前先放好 EXE。以后移动程序，请重新保存设置更新快捷方式。卸载前在设置中关闭自启，退出程序，再删除便携文件夹；个人配置可按需保留。

此版已完成自动检查和独立 EXE 启动验证；搜狗拼音/浏览器/记事本的完整 UAT 仍待反馈。窗口自动切换继续冻结。遇到问题请在 https://github.com/ziyumieming/Ime-2Chinese/issues/4 反馈版本、步骤和诊断快照。
