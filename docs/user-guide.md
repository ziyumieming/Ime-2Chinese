# 使用指南

## 当前可运行内容

需要 Windows 和 AutoHotkey v2。

- `main.ahk --check`：检查主入口与 App 加载，然后退出；不注册热键、不操作输入法。
- 双击 `main.ahk`：常驻托盘；生成和读取用户配置，支持暂停、功能偏好开关、重载和退出。目前不占用重喂/取回热键，也不执行自动切换。
- `tests/ime-smoke.ahk`：可选的真实桌面模式检测/切换工具，步骤见 [测试方案](testing-strategy.md)。
- `tests/refeed-mvp.ahk` 或 `main.ahk --test-refeed`：显式启动 P2 重喂/取回测试入口，使用配置中的热键、长度和间隔；详见 [MVP 说明](refeed-mvp.md)。
- `src/core.ahk`：原始重喂/取回 demo，可独立运行。
- `src/test.ahk`：原始状态探测 demo，按 `F1` 显示探测字段，不提供模式切换。

P1 配置与托盘可用，P2 仅在测试入口接入，P4 自动切换尚未接入。不要把原型或诊断结果当作新工具已通过真实应用兼容验收；不要同时运行注册相同热键的旧 demo 和重喂测试入口。

## 原型操作

先手动让中文输入法处于中文模式，选中误输的英文字母，按 `Alt+Z`。demo 接受不超过 50 字符的字母和空白，移除空白后逐键发送，间隔 10ms；不自动选词。

`Alt+Shift+Z` 在当前光标/选区处原样插入最近缓存的原文，可以跨窗口重复使用。它不是撤销，不主动删除重喂结果；需要撤销时使用当前应用的 `Ctrl+Z`，具体效果由应用决定。

demo 尚无自动确认中文状态、焦点保护和完整异常清理，真实应用兼容性待验证。请使用人工测试文本，不在重要内容上首次试验。

## 配置与托盘

首次启动在 `%AppData%\ImeAssist\settings.ini` 生成 UTF-8 配置；以后读取该文件，不覆盖已有无效文件。仓库中的 `config/settings.example.ini` 供参考。

托盘提供暂停/恢复、两项功能偏好开关、打开配置、重载、最近诊断和退出。尚未接入的功能会在菜单中标明；勾选只是保存偏好。暂停不写入配置，重新启动时恢复正常运行状态。开关保存会先读取文件，保留并应用尚未重载的有效改动；非法文件会拒绝保存。保存时规范化配置格式，保留规则顺序，注释不保留。

配置校验规则：

- 开关为 0/1；发送间隔 1–1000ms、长度上限 1–500、复制等待 50–5000ms、监听间隔 100–5000ms。默认值仍为 10ms、50、300ms、300ms。
- 热键使用 AHK 修饰符 `^`（Ctrl）、`!`（Alt）、`+`（Shift）、`#`（Win）和单个按键，例如 `!z`、`!+z`、`^!F8`；不支持组合按键或左右修饰键扩展语法。两项热键不能相同。
- IME 目标为 SogouPinyin 或 MicrosoftPinyin；DefaultAction 必须为 Ignore。
- 规则按 INI 顺序排列，节名 `[Rule.唯一编号]`，包含 Process、可选 TitleContains、Mode；动作仅支持 Chinese、English、Ignore。规则引擎在 P3 接入，目前只校验和保留规则。
- 未知键、重复节/键、无效值会拒绝加载；启动时退出，重载时保留上一次有效配置。运行时热键注册失败会清理部分注册并尝试恢复原绑定；无法恢复时停用绑定并提示。

热键校验不能保证与其他应用的快捷键无冲突；主程序单实例，不与原型同时注册相同功能热键。最近诊断仅存内存中最多 30 条状态记录，不保存原文、剪贴板或窗口标题。

## 后续输入能力

主力是搜狗拼音，微软拼音用于兼容测试。重喂会按配置激活中文输入法；自动规则只改变当前受支持中文输入法的中英文模式，尊重手动选择，不替换日语或英语键盘。

上述指定输入法激活是完整版本的目标，当前 MVP 要求已手动启用配置目标；不符合时在删除前退出。取回仅插入缓存，不是 Ctrl+Z。字段与模式修正见 [诊断说明](ime-diagnostics.md)。

可以管理员身份常驻，权限不足时的提示/提升流程留待后续处理。现阶段主要验收浏览器和记事本，不启动 VS Code。

进度与可用能力以 [ROADMAP](../ROADMAP.md) 及 [兼容记录](../tests/compatibility-results.md) 为准。
