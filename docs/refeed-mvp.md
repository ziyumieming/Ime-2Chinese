# 重喂 MVP 测试

这是显式启用的测试版本。用户已反馈 smoke 中英文切换符合预期、取回正常、重喂多数正常；本轮修正热键焦点、首字符时序、切回输入法后的误拒绝及空选区行为，修正版真实桌面待复测。普通双击 `main.ahk` 仍只启动配置和托盘。

## 启动

退出旧 `src/core.ahk` demo 和正在运行的主程序，再双击 `tests/refeed-mvp.ahk`；或运行 `main.ahk --test-refeed`。需要 AHK v2，使用自己的正常桌面账户。该入口加载同一个 App 和用户配置，托盘会标明“重喂测试版”；配置中的功能开关及热键仍有效。

按 [Issue #1 的最新决定](https://github.com/ziyumieming/Ime-2Chinese/issues/1)，重喂只改变当前中文输入法的中英文内部模式，不激活另一输入法，不恢复原模式。英文键盘布局与“搜狗内部英文模式”不同：当前版本处理可观察的简体中文输入法上下文，其他语言布局跳过。`RefeedTarget` 保留以兼容已有配置，不再作为激活要求或基于线程提示的硬门槛。

## 最小操作

1. 在空白记事本或 `tests/browser-input.html` 输入 `ni hao`，确保当前没有未提交的候选/组合文本；先切到搜狗英文，再选中完整文字。
2. 按 `Alt+Z`。程序先观察是否确有选区，再复制校验；确认中文后再次核对选区，等待模式稳定、删除，并在发送首字符前再次确认稳定。停在候选状态，由你选词。
3. 选词后，在另一处或另一窗口按 `Alt+Shift+Z`，应插入完整的 `ni hao`；可以重复取回。
4. 用数字、标点、纯空白或超长文本尝试拒绝路径，原文应保留，之前的有效缓存也应保留。

不选中文字空按热键应静默返回，不清空剪贴板、不发送 Ctrl+C。切到其他语言再切回搜狗后，不应因旧 profileHint 拒绝重喂。

菜单可暂停/恢复、打开设置、诊断及退出。偏好仅从设置窗口修改，支持按键录制和登录后自启。退出清空原文缓存，只运行一份功能脚本。此入口不启用自动切换；历史实现见 [全功能 MVP](auto-switch-mvp.md)。

## 已实现的保护

- 长度在去空白前计算，默认上限 50，保留大小写及全部原文空白；默认发送间隔 10ms。
- 热键强制使用键盘钩子；Alt 菜单使用无分配键抑制，不通过 Esc 抢焦点。其他全局工具仍可能占用同一热键，实际冲突待复测。
- 传统 Edit/RichEdit 用选区端点观察，其他控件用有超时配置的 UI Automation TextPattern，不读取全文。未知选区和密码框静默跳过，不尝试复制；可用 UIA 提供者下逐步核对同一焦点元素。
- 在复制与模式切换前检查可编辑性：Edit/RichEdit 检查启用、密码与只读样式；UIA 结合文本控件类型及只读元数据，不要求 ValuePattern。正文/只读/禁用/密码/未知目标静默，取回也适用；cmd/Windows Terminal 目前明确跳过。按键后才检查，无新增轮询。
- 最后复制后及删除后分别要求连续 100ms 中文读回；删除后失败保留完整缓存，不发送首字符。IMM 稳定仍不等于真实候选效果已验证。
- 复制等待有界；热键修饰键未释放、焦点未知/变化、文本非法、中文确认失败或二次选区不一致，在删除前退出。
- 共享重入锁；删除/发送中出错或目标变化，停止发送并保留缓存供取回，不向新窗口回滚。
- 剪贴板备份全部格式；按序列号跟踪本工具的数据，外部更新时保留新内容。复制来源进程无法确认时拒绝。统一清理路径及退出清理释放备份。
- 取回通过 SendText 在当前目标插入，不取消候选，不清除之前重喂结果，不接管 Ctrl+Z。
- 诊断关联每次操作的阶段、耗时及系统状态，记录已取得的选区和完整标题，显示失败阶段、发送调用数、缓存状态；有界内存、回调刷新及主动导出，无额外复制或自动落盘。

## 待验收的范围

已有候选的自动检测仍待验证。新增 UIA 元素检查增加了同窗口不同输入框的保护，Chrome 实际提供者行为待 UAT；提供者不支持观察时跳过，不能承诺兼容全部网页编辑器。测试仍用无候选的人工样例。

权限差异、更多网页编辑器、已有候选下取回的应用副作用仍待验收；P6 普通入口现已默认启用手动功能。指定输入法激活已按新需求移出范围。

结果可回复 [测试环境 Issue](https://github.com/ziyumieming/Ime-2Chinese/issues/2) 或聊天，本地 REVIEW_QUEUE 不再维护。注明实际观察即可，不要求每轮查版本。字段见 [诊断说明](ime-diagnostics.md)，策略见 [测试方案](testing-strategy.md)。
