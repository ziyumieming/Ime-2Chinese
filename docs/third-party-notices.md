# 第三方组件

可执行文件内包含未修改的 AutoHotkey v2.0.19 x64 运行时；通过官方 Ahk2Exe v1.1.37.02a2 嵌入应用脚本、图标和版本资源。构建未启用 UPX/MPRESS 压缩。

AutoHotkey 的运行时使用 GNU GPL v2；包内 `third-party/AutoHotkey-GPL-2.0.txt` 保留完整许可证，`third-party/AutoHotkey-v2.0.19-source.zip` 提供对应运行时源代码。该说明不替用户决定独立应用脚本或所提供头像的授权方式。

- 运行时：https://github.com/AutoHotkey/AutoHotkey/tree/v2.0.19
- 编译器：https://github.com/AutoHotkey/Ahk2Exe/releases/tag/Ahk2Exe1.1.37.02a2
- 应用源码与构建脚本：https://github.com/ziyumieming/Ime-2Chinese

`build-info.json` 记录使用版本、上游下载地址/SHA-256、应用源提交、工作树是否有未提交修改及 EXE 校验值。
