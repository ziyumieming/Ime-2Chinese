# 手动验收清单

本文件只列测试用例，勾选必须有实际结果。完整门槛见 [PLAN](../PLAN.md)，进度见 [ROADMAP](../ROADMAP.md)。

## P0 输入法控制

- [ ] 搜狗在记事本、常用浏览器内的中文/英文状态可识别。
- [ ] EnsureChinese / EnsureEnglish 可验证成功，重复调用不翻转。
- [ ] 英语键盘/日语空按重喂静默跳过；切回中文输入法后可再次重喂，不强行激活其他输入法。
- [ ] 选区、已有候选、同窗不同编辑框、不可用状态和超时有记录。
- [ ] 微软拼音完成相同基础案例，差异单独记录。

## P2 重喂与取回

- [ ] `nihao`、`ni hao` 进入候选，不自动提交；大小写按原样发送。
- [ ] 50 字符可接受，51 字符拒绝，长度在去空白前计算。
- [ ] 无选区、纯空白、中文/数字/标点及失败前置条件不删除原文。
- [ ] 无效请求不覆盖原文缓存；取回保留空白，可跨窗口重复插入。
- [ ] 删除前/发送中换窗及同窗焦点变化不会继续发送到新目标，记录检测限制。
- [ ] 剪贴板文字、富文本、图片及中途新复制按约定处理。
- [ ] 已有候选时取回、应用 Ctrl+Z 的实际行为有记录。
- [ ] 无选区空按热键无提示、无 Ctrl+C，剪贴板保持不变；不支持的编辑框也静默跳过。
- [ ] Alt+Z 在记事本/Chrome 不激活菜单、不丢失编辑焦点；修饰键释放后正常发送。
- [ ] 从输入法内部英文切为中文重喂，首个字母也进入中文候选，多次重复符合预期。

## Issue #4 新待办验收（实现后执行）

- [ ] 网页正文/只读框/禁用或未知目标不复制、不切换、不删除、不发送；可编辑性检查先于复制。
- [ ] 可编辑框无选区时重喂静默；有缓存时取回仍可在光标处插入，不要求选区。
- [ ] 浏览器普通输入框、contenteditable、多行框兼容；密码框跳过。
- [ ] 按键后检查，不新增可编辑状态轮询；无效场景吞键为接受的行为。
- [ ] 诊断可关联操作阶段、IME 原始值、耗时、错误和删除/缓存后果；选中文本与完整标题可供排错。
- [ ] 回调更新及快照导出可用，无额外轮询，关闭/退出清理正确，记录容量有界。

## P3/P4 规则与自动切换（历史清单，已冻结）

- [ ] 进程、标题、规则顺序、Ignore、无匹配结果正确。
- [ ] 进入/返回窗口应用一次，同规则标题刷新不重复应用。
- [ ] 手动切换受尊重，规则变化才重新应用；英语键盘/日语不被自动替换。
- [ ] 重喂与自动切换不争抢状态，暂停/恢复和重载符合约定。
- [ ] 重喂后同窗口访问期间，标题变化/重载/恢复不改变候选状态；离开再返回时重新应用规则。

## P5/P6 日常使用与打包

- [ ] 配置保存、热键校验、启停、退出和诊断完成验收；普通/重喂入口无新增空闲轮询。
- [ ] 设置使用 Alt+Z 等可读快捷键，保存后新键生效/旧键退出；暂停中保存保持暂停。
- [ ] 文件修改规则与窗口修改其他偏好可合并；同字段不同改动提示冲突，重新读取后可保存。
- [ ] 设置关闭保留草稿，诊断刷新/清空与缩放正常；实际字体/DPI 下控件可读。
- [ ] 长时间同窗空闲不反复切换或提示，记录实际 CPU/内存观察；模拟检查不当作真实负载验收。
- [ ] 打包产物入口与核心流程回归通过，源码/产物对应关系明确。
- [ ] 浏览器/记事本 × 搜狗/微软结果已记录；VS Code 标为未测试。
